# Design system — before implementation

Direction: calm, intelligent learning workspace. Spacious sidebar + open content, a lime learning-plan band, thin ruled lesson list, white graph canvas and understated progress bars. No cartoon illustration or repeated card grid.

Tokens: canvas #f7f9f8; surface #fff; ink #1c2925; muted #718078; forest #174c3c; pale lime #e9f2d9; accent #d8efad; border #e1e7e3; warning #b27e36. 8px spacing unit, 12–20px surface radius, no heavy shadows.

Typography: Inter/system sans; headings 36/28/22, body 15–16, labels 12–14. Buttons 14px semibold. Sidebar 224px, content max 1240px. Desktop main split 62/38; tablet stacked canvas, mobile compact nav and one column. Interactive graph rendered with native SVG and accessible skill buttons, not a bitmap.

Components: Shell, Icon, Button, PageHeading, SubjectTabs, MasteryBar, KnowledgeGraph, learning rows, form fields, status/error notices, lesson stepper, conversation turns. Shared families extend to login, onboarding, diagnostic, subject detail, lesson, speaking/listening, progress, parent analytics/report and admin editor.

Concept source and final fidelity notes will be stored under docs. Actual seed metrics and planner data may replace example text; Ukrainian translations and mock-mode notice are required functional deviations from an English concept.
